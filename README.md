# سنجش‌نما: سایت رتبه‌بندی مواضع و عملکرد

سایت استاتیک فارسی که خبرها را از RSS می‌خواند، با مدل زبانی (Gemini و در صورت خطا Groq) بر اساس معیارهای شما نمره می‌دهد و رتبه می‌سازد. همه‌چیز رایگان اجرا می‌شود:

- **GitHub Actions** هر ۶ ساعت اسکریپت‌ها را اجرا می‌کند.
- **GitHub Pages** (یا Cloudflare Pages) پوشه‌ی `docs/` را به‌عنوان سایت نشان می‌دهد.
- نیازی به PHP، دیتابیس یا هاست پولی نیست.

## ساختار

```
config/people.json       شخصیت‌ها (نام، سمت، توییتر، نام‌های دیگر)
config/rubric.json       اصول و معیارها و پله‌های نمره‌دهی
config/feeds.json        آدرس RSS خبرگزاری‌ها
config/settings.json     تنظیمات (مدل‌ها، آستانه‌ها، متن سایت)
config/overrides.json    تصمیم‌های ویراستار (تأیید، رد، اصلاح نمره)
config/manual_items.json توییت یا خبری که خودتان دستی اضافه می‌کنید
scripts/                 خواندن RSS، تحلیل، محاسبه‌ی رتبه
data/                    حافظه‌ی خط لوله (news.json، analyses.json)
docs/                    خود سایت (HTML/CSS/JS و data/scores.json)
review/index.html        ابزار بازبینی که روی رایانه‌ی خودتان باز می‌شود
```

## تست محلی (بدون اینترنت و بدون کلید)

```bash
python3 scripts/run_all.py --mock --allow-file --feeds tests/feeds_local.json
cd docs && python3 -m http.server 8000
```

حالت `--mock` تحلیل آزمایشی ساده‌ای انجام می‌دهد و سایت را با برچسب «داده‌ی آزمایشی» می‌سازد. بعد از تست، پوشه‌های `data/` و `docs/data/` را پاک کنید.

## راه‌اندازی واقعی

1. **پیکربندی** (مهم‌ترین مرحله)
   - در `config/people.json` شخصیت‌های واقعی را بنویسید. برای جلوگیری از اشتباه، نام کامل یا نام‌های دیگر دقیق را در `aliases` بگذارید، نه فقط نام خانوادگی.
   - در `config/rubric.json` اصول اعلام‌شده را با متن و منبع دقیق و معیارها را با جمله‌بندی خودتان بنویسید، بعد `"is_template"` را `false` کنید. تا وقتی `true` باشد، تحلیل واقعی اجرا نمی‌شود.
   - در `config/feeds.json` آدرس RSS خبرگزاری‌ها را بگذارید (معمولاً در پایین یا صفحه‌ی «RSS» هر سایت خبری هست) و `enabled` را `true` کنید.
   - در `config/settings.json` عنوان سایت و `contact_email` را عوض کنید. این ایمیل عمومی نمایش داده می‌شود.

2. **کلید API**: از Google AI Studio کلید Gemini و در صورت دسترسی از Groq کلید بگیرید. در GitHub: Settings ← Secrets and variables ← Actions ← New repository secret، با نام‌های `GEMINI_API_KEY` و `GROQ_API_KEY`.

3. **انتشار سایت**: Settings ← Pages ← Deploy from a branch ← شاخه‌ی main و پوشه‌ی `/docs`.

4. **اولین اجرا**: تب Actions ← update ← Run workflow. بعد از آن هر ۶ ساعت خودکار اجرا می‌شود.

## بازبینی انسانی (توصیه‌ی جدی)

- تحلیل‌هایی که اطمینان‌شان کمتر از آستانه است یا نقل‌قولشان عیناً در متن خبر نیست، **منتشر نمی‌شوند و در رتبه حساب نمی‌شوند** تا شما بازبینی کنید.
- فایل `review/index.html` را روی رایانه‌ی خودتان باز کنید (بعد از دانلود مخزن). هر مورد را تأیید، رد یا نمره‌اش را اصلاح کنید و در پایان فایل `overrides.json` را دانلود و در `config/` جایگزین کنید (در GitHub می‌توانید با Upload files آن را آپلود کنید).
- در اجرای بعدی، تصمیم‌های شما اعمال می‌شود. موارد تأییدشده با وزن کامل حساب می‌شوند.

## توییتر (X)

خواندن خودکار توییت‌ها پولی است و ناپایدار، پس در این نسخه نیست. دو راه دارید:
- هر توییتی که می‌خواهید حساب شود را در `config/manual_items.json` بگذارید:
  ```json
  [{"person_id": "sample-1", "source": "X", "url": "https://x.com/...", "date": "2026-11-04", "text": "متن توییت"}]
  ```
- یا بعداً یک منبع داده‌ی پولی به `fetch_news.py` وصل کنید.

## نکات مهم

- **شفافیت**: صفحه‌ی «روش‌شناسی» خودکار از `rubric.json` ساخته می‌شود و معیارها را علنی می‌کند. این را حذف نکنید.
- **حقوقی**: سایتی که درباره‌ی افراد واقعی نمره منتشر می‌کند در معرض شکایت افترا است. برای هر نمره منبع و نقل‌قول نشان داده می‌شود و پیوند «گزارش خطا» هست؛ به گزارش‌ها رسیدگی کنید.
- **دقت**: مدل کنایه و نقل‌قول از دیگران را گاهی اشتباه می‌خواند. فقط متن RSS (عنوان و خلاصه) خوانده می‌شود، نه متن کامل خبر.
- **سهمیه**: `max_per_run` در تنظیمات، تعداد تحلیل در هر اجرا را محدود می‌کند تا از سقف رایگان نگذرد.
- **کلید API** را هرگز در فایل‌ها نگذارید؛ فقط در Secrets.
- **دسترسی از ایران**: سرویس‌های Gemini و Groq ممکن است ساخت کلید یا ثبت‌نام را از ایران نپذیرند. شرایط هر سرویس را قبل از شروع بررسی کنید.
- فونت سایت فونت‌های سیستم است (بدون Google Fonts) تا در شبکه‌های محدود هم سریع باز شود.
